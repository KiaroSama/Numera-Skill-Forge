# Contributing

Start with the glossary in CONTEXT.md and current capability evidence. Add content with a registry
record rather than hard-coded package names. New host APIs require primary documentation, exact
version/surface constraints, honest fidelity and contract tests before support is advertised.

Preserve original licensing/bytes and companion files; no executable inspection without distinct
approval. Test public service boundaries with first-party fixtures. Keep modules responsibility-named
and below 800 lines. Source builds use pinned toolchain and lockfiles; final CI must pass.
